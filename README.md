# webtoon-content

Content packs of the Toonfork reader app (format: `PACK_FORMAT.md` in the app repo, catalog schema 2).

- `catalog.json` and `covers/` are served by GitHub Pages: https://lioilsources.github.io/webtoon-content/catalog.json
- Pack zips are assets of the GitHub Releases `pack-<type>-<n>-v<version>`; the app composes their URL from
  `base_urls.releases` and verifies each part's SHA-256.
- Generated by `webtoon export-pack -type <type> -n <n> … -out <this checkout>`; zips are never committed.
